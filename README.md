# Cyber Escape Room Game

## About the Project
Cyber Escape Room is an interactive, browser-based game based on Cyber Security.

In this game, the player is trapped inside a server room and must complete four different stages to escape successfully.

## Game Objectives
- Explore the cyber security environment.
- Solve challenges in each stage.
- Unlock all four stages.
- Complete the final objective to win the game.

## Features
- Interactive gameplay.
- Four challenging stages.
- Cyber Security-based theme.
- HTML-based web application.
- Simple and user-friendly interface.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Play
1. Open the game in your web browser.
2. Start the Cyber Escape Room challenge.
3. Complete the four stages one by one.
4. Unlock all stages.
5. Reach the final objective and win the game.
